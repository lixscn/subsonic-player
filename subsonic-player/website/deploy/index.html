Subsonic Player
桌面与手机上的专业音乐播放器

连接你自己的音乐服务器（Subsonic / Navidrome / Gonic / Jellyfin / Emby / Plex / 群晖 AudioStation）， 享受 Roon 风格的浏览体验、10 段 EQ、卡拉OK 滚动歌词、Gapless 无缝播放，Android 端还能 DLNA 投送到音箱与电视。桌面版与 Android 原生客户端，免费开源。

功能一览

桌面端能力全，移动端按竖屏重做 —— 同一套曲库，两种形态。

曲库浏览与发现

艺术家 / 专辑 / 歌曲三级浏览、封面墙、全局搜索；发现页提供随机推荐与基于收藏偏好与流派亲和的智能推荐，还有最近添加、常听、高分、按流派与年代浏览。

播放与音效

HTTP 流式播放、队列管理、顺序 / 随机 / 列表循环 / 单曲循环；Gapless 无缝播放与 0–15 秒交叉淡入淡出；10 段图形 EQ（摇滚 / 流行 / 古典 / 人声 / 重低音预设，可导入导出）与混响、回声、合唱、压缩器等 DSP。

卡拉OK 歌词

优先读取服务端同步歌词，失败时并行回退 LRCLIB 与网易云；当前行放大高亮、前后行渐隐的滚动效果，并做本地缓存，二次打开秒出。

多协议兼容

原生 Subsonic / OpenSubsonic（Navidrome、Gonic、Jellyfin 等），并额外支持 Emby、Plex、群晖 AudioStation；可配置多个服务器，内网优先、外网自动回退。

媒体管理

歌单增删改、添加到歌单、收藏（红心）、1–5 星评分、分享链接、下载原文件；播放历史与 scrobble 上报。Android 版还会把听过的曲子整首缓存到本机（重播零流量），已缓存的曲目在播放页与播放队列标注「本地」。

Android 原生客户端

纯原生实现，后台播放 + 通知栏与锁屏控制 + 耳机按键 + 音频焦点；底部导航与全屏播放页按手机竖屏重做，支持播放位置记忆与断点续播。还内置 DLNA / UPnP 投送：把音乐推到局域网音箱、电视和功放，手机当遥控器。

主题与个性化

6 套内置主题（深邃黑 / 月光白 / 森林绿 / 午夜蓝 / 落日橙 / 玫瑰紫）与多套强调色，深浅色随主题一键切换。

隐私与自托管

没有账号体系、没有云端曲库：所有数据都在你自己的服务器上。客户端凭据加密存储（Windows DPAPI / Android KeyStore），不硬编码、不上传。

常见问题

Subsonic Player 是免费的吗？
客户端完全免费且开源（MIT 协议）。音频引擎 BASS 系列为 Un4seen 产品，个人非商业使用免费，商用需另行授权。
支持哪些音乐服务器？
原生支持 Subsonic / OpenSubsonic 协议（Navidrome、Gonic、Jellyfin 等兼容实现），并额外支持 Emby、Plex 和群晖 AudioStation；可以配置多个服务器并一键切换。
Windows 版为什么体积比较大？
桌面版内置 Chromium（CEF）用于渲染界面，并自带 .NET 运行时，所以不需要你另外安装任何环境 —— 解压就能用。
Android 版支持哪些音频格式？
内置解码器（BASS 核心 + add-on 插件）：mp3 / m4a(AAC) / FLAC / WAV / OGG，以及 DSD（.dsf）、APE、WavPack、Opus —— 服务端不做转码也能直接播放。服务端对 APE/DSD 这类文件常常不返回后缀，客户端会用 contentType 兜底识别。
Android 版能推送到音箱或电视播放吗？
可以。Android 版内置 DLNA / UPnP 投送：自动发现同一局域网里的音箱、电视与功放，选定后由那台设备直接从你的音乐服务器拉流播放，手机当遥控器 —— 支持播放 / 暂停 / 上一首 / 下一首 / 拖动进度 / 调节音量，一首放完自动续播下一首；断开连接或切回本机播放时，声音自动交还手机。注意音箱需要能访问到你的音乐服务器地址（一般同一局域网即可）。
数据会被上传到云端吗？
不会。客户端没有账号体系，所有请求都直接发往你自己的服务器；服务器密码加密保存在本机（Windows DPAPI、Android KeyStore）。
支持歌词吗？
支持。优先使用服务端同步歌词，取不到时自动回退 LRCLIB 与网易云，并做本地缓存；桌面与 Android 端都有卡拉OK 式滚动高亮。
