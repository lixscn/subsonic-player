# 参考项目 UI/功能分析（Sonixd & Musiver）

> 记录时间：2026-08。分析两个开源 Subsonic/NAS 音乐客户端，提炼可借鉴的设计与功能。**仅记录，暂不实施，后续再决定。**

## 分析对象

| 项目 | 技术栈 | 特点 |
|------|--------|------|
| [Sonixd](https://github.com/jeffvli/sonixd) | Electron + React + rsuite | 经典桌面 Subsonic 客户端（已归档，继任者 Feishin） |
| [Musiver/音流](https://github.com/liuyincs/musiver) | Flutter | 跨平台 NAS 音乐播放器（Android/iOS/macOS/Windows/tvOS/Web/HarmonyOS） |

> Musiver 的 GitHub 仓库只用于 issue/文档（Docusaurus 站），不含应用代码；官网与仓库截图多为营销图，仅「正在播放页」有一张真实界面图。Sonixd 有完整界面截图（album/artist/search/now_playing）。

## 一、Sonixd 界面分析

### 1. 左侧导航
- 图标 + 文字组合
- **底部显示当前播放歌曲封面缩略图 + 标题/艺术家/专辑**（迷你正在播放卡）

### 2. 专辑页
- **自适应网格**：按窗口宽度自动换行，专辑卡片统一尺寸
- 专辑卡片 = 封面 + 标题 + 艺术家（+ 年份），hover 显示播放按钮

### 3. 专辑详情页
- 顶部**大横幅卡片**：大封面（~200px）+ 专辑名/艺术家/年份 + 播放/收藏/下载按钮
- 下方**歌曲表格**：`# 时长 标题 艺术家 专辑 流派` 多列、表头排序、行高 35-40px、每行小封面

### 4. 艺术家详情页
- 顶部**大卡片横幅**：大封面 + 艺术家名 + 统计（"XX albums · XX songs · XX 时长"）+ 简介 + 操作按钮
- 下方分块：**Top Songs 列表** + **Latest Albums 横向滚动卡片流**

### 5. 正在播放页
- 左侧栏下部大封面 + 标题/艺术家/专辑三行
- 右侧**队列表格**：`# 时长 标题 艺术家 专辑 流派`，当前播放行高亮（灰底 + 标题绿色）
- 右键菜单丰富：播放/入队/移除/移到/加歌单

### 6. 搜索结果
- 右侧浮动面板：艺术家/专辑/歌曲三类分栏、可折叠、可 Load more，专辑项 = 小封面 + 标题 + 年份 + 艺术家

## 二、Musiver（音流）分析

### 界面
- **正在播放页**（唯一真实截图）：**黑胶唱片式大封面**（圆形封面 + 唱片边框，视觉锚点）+ 逐行滚动歌词（当前行高亮）+ 顶部标签页（推荐/歌曲/歌词）+ 沉浸式深色渐变背景
- 深棕/黑灰/米色配色，极简沉浸式风格，圆角设计

### 功能/特性
- **多平台**：Android / iOS / macOS / Windows / Apple TV / Web / HarmonyOS
- **多服务统一**：Subsonic / Navidrome / Emby / Jellyfin / AudioStation / Plex / Audiobookshelf
- **歌词**：多服务歌词 + **自定义 API 兜底**（不提供歌词的服务也能显示歌词）
- **无损解码 + 智能缓存 + 离线模式**
- 基于元数据的音乐库浏览、封面/歌词/信息展示
- 多服务器与多线路支持

## 三、共同可借鉴点（对照我们项目）

| 设计/功能 | Sonixd | Musiver | 我们现状 | 是否需要 |
|-----------|--------|---------|----------|----------|
| 专辑/艺术家详情页**顶部大横幅卡片**（封面+名字+统计+按钮） | ✅ | ✅ | ❌ 信息少 | ⭐ 高优先 |
| 专辑库**自适应封面网格**（hover 播放） | ✅ | ✅ | 横向滚动卡片流 | ⭐ 高优先 |
| **播放队列表格化**（# 时长 标题 艺术家 专辑 多列 + 表头排序） | ✅ | ✅ | 固定宽列表 | ⭐ 高优先 |
| 当前播放行**灰底 + 标题绿色**（更醒目） | ✅ | ✅ | 有绿色高亮 | 中（加强） |
| 左侧导航底部**当前播放迷你卡**（封面+标题+艺术家） | ✅ | ❌ | ❌ | 中 |
| 艺术家**统计信息**（X 专辑·X 歌曲·X 时长） | ✅ | ❌ | ❌ | 中 |
| 正在播放**黑胶唱片式大封面** | ❌ | ✅ | 方形封面 | 低（风格取舍） |
| 正在播放**标签页切换**（推荐/歌曲/歌词） | ❌ | ✅ | 歌词+队列分栏 | 中 |
| **歌词自定义 API 兜底** | ❌ | ✅ | LRCLIB 兜底 | ✅ 已有 |
| 右键菜单（入队/移除/移到/加歌单） | ✅ | ✅ | 加号菜单 | ✅ 已有 |
| 多服务统一接入 | ✅ | ✅ | 6 服务 | ✅ 已有 |
| 智能缓存/离线 | ❌ | ✅ | SQLite 缓存 | 中（离线模式待定） |
| 搜索结果分类面板 | ✅ | ❌ | 搜索页 Tab | 低（可选优化） |

## 四、优先级建议（后续决定）

1. **专辑/艺术家详情页大横幅卡片** —— 信息集中、视觉冲击强，改动成本中等
2. **播放队列表格化 + 表头排序** —— 信息密度高，与我们「正在播放」队列强相关
3. **专辑库自适应封面网格** —— 浏览体验提升明显
4. 当前播放行高亮加强、左侧导航底部播放卡、艺术家统计 —— 小改动，提升精致度
5. 正在播放页标签页（推荐/歌曲/歌词）、黑胶封面 —— 风格性改造，待定
